enumerate() lets you loop over something and get the index and the value together.

fruits = ["apple", "banana", "mango"]

for index, fruit in enumerate(fruits):
    print(index, fruit)

Output:

0 apple
1 banana
2 mango

A docstring is a string used to explain what a function, class, or module does. It helps developers understand the purpose of the code.

Python docstrings are written using triple quotes (""" """) immediately after the function, class, or module definition.
